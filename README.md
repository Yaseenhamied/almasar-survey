# Al-Masar Insurance — Management discovery survey

- `index.html` — the survey (Arabic / English, print and save as PDF).
- `dashboard.html` — private results board (needs the key stored in the Google Sheet).
- `questions.js` — the question set shared by both pages.
- `config.js` — the Google Apps Script Web app URL that stores answers.
- `apps-script/Code.gs` — paste into the Google Sheet's Apps Script editor.

Answers are never stored in this repository. They go to a private Google Sheet.
